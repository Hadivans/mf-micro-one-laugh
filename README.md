# One Line, One Laugh

A make.fun one-liner entry: one funny line, at most 200 characters.

> My bank called to say my account is overdrawn, which is impressive,
> because when I checked yesterday it was only emotionally overdrawn.

`main.py` (stdlib only) writes that single line to `entry.txt` in
`MAKEFUN_OUTPUT_DIR` (default `output/`).
